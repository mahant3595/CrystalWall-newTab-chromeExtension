# CrystalWall-newTab-extension

## Wallpapers

Open Settings to browse the included system wallpapers and your uploaded wallpapers in separate collapsible sections. Each section scrolls independently; hold and drag the hand-pointer control to reposition a wallpaper with a live preview, click it to move that wallpaper to the top, or use the arrow keys to reorder it. The bundled wallpaper in `assets/wallpaper.jpg` is the default on a fresh install. Image and video uploads are stored locally in the browser.

You can also fetch a direct image or video URL. The remote server must permit cross-origin access; the extension asks for access to that specific site when needed. Resetting Wallpaper or Music lets you optionally delete that section's uploaded files; this deletion cannot be undone. Weather icons use the browser's location permission and Open-Meteo, which receives the coordinates to return local conditions. Weather data is cached locally for 30 minutes.

All bundled wallpaper assets use the `.jpg` format. Raster artwork keeps its original dimensions and aspect ratio; vector artwork is rasterized without landscape conversion.
