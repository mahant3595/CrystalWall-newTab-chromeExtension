# CrystalWall-newTab-extension

## Wallpapers

Open Settings to browse the included system wallpapers and your uploaded wallpapers in separate collapsible sections. Each section scrolls independently; hold and drag the hand-pointer control to reposition a wallpaper with a live preview, click it to move that wallpaper to the top, or use the arrow keys to reorder it. The bundled wallpaper in `assets/wallpaper.jpg` is the default on a fresh install. Image and video uploads are stored locally in the browser.

You can fetch direct image or video URLs and page URLs that expose an Open Graph or Twitter image/video address. If a site blocks access or hides media behind sign-in or scripts, a help popup explains the issue and shows any page or media address that was found. You can paste a copied image with the Paste image button or Ctrl+V, or upload an image/video file. The extension requests access to HTTP and HTTPS websites to follow redirects across domains and uses clipboard read/write permissions for pasting images and copying addresses. Resetting Wallpaper or Music lets you optionally delete that section's uploaded files; this deletion cannot be undone. Search suggestions show matching recent or cached results immediately while fresh suggestions load. Location-based weather is off by default and can be enabled in Settings > Quotes; when enabled, the browser's location permission is used and Open-Meteo receives the coordinates to return local conditions. Weather data is cached locally for 30 minutes.

All bundled wallpaper assets use the `.jpg` format. Raster artwork keeps its original dimensions and aspect ratio; vector artwork is rasterized without landscape conversion.
